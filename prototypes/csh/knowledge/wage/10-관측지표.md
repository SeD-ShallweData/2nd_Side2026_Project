# 임금체불 — 관측 지표와 그 의미

모델이 보는 신호를 사용자 언어로 옮긴 것이다. 각 지표는 **관찰된 사실**이지 체불의 증거가 아니다.

## 위험 쪽 신호

| 지표 | 데이터에서 보이는 것 | 왜 신호인가 |
|---|---|---|
| **최근 3개월 결측** | 국민연금 데이터에 해당 월 기록이 없음 | 가장 강한 단일 신호. 탈퇴 임박 또는 보험료 체납 |
| 가입자 수 감소 | 12개월 순고용변화율 < -0.15 | 인력 이탈 또는 구조조정 |
| 1인당 고지금액 하락 | 연속 하락 3개월 이상 | 임금 삭감·단축근로. 자금난의 지속성 |
| 짧은 업력 | 설립 4년 이내 | 신생 사업장의 소멸률이 높음 |
| 이직률 급증 | 입·퇴사 변동이 동종업계 대비 큼 | 내부 문제의 간접 신호 |
| 4대보험 체납 | 건강보험 체납 공개명단 등재 | 지급 순서상 급여보다 먼저 밀린다 |
| **체불사업주 명단 등재** | 고용노동부 공개 명단에 있음 | **예측이 아니라 정부가 공개한 사실** |

**결측을 0으로 채우지 않는다.** 결측 자체가 가장 강한 피처다.

회사 현금이 마르면 지급 순서가 대체로 이렇게 밀린다:
4대보험료·세금 → 협력업체 대금 → 상여·수당 → 기본급.
그래서 보험료 체납은 급여가 밀리기 **몇 달 전에** 먼저 나타나는 경우가 많다.

## 안정 쪽 신호 (green flag 6종, 최근 12개월 관찰)

| | 지표 | green 조건 |
|---|---|---|
| G1 | 고용안정 | 가입자 첫달 대비 5% 초과 감소 없음 |
| G2 | 성실납부 | 12개월 결측 0 (매월 데이터 존재) |
| G3 | 인건비안정 | 1인당 인건비 5% 초과 하락 없음 |
| G4 | 인력유지 | 누적 신규 ≥ 누적 상실 |
| G5 | 업력3년 | 가입 후 3년 이상 |
| G6 | 낮은변동성 | 가입자 변동계수 ≤ 0.15 |

## "점수가 낮다 = 안전"이 성립하지 않는 이유

라벨 구조가 Positive-Unlabeled다.

- 양성 = 명단공개된 체불사업주 (고액·상습·확정) — 극히 일부
- 음성 = "아직 명단에 오르지 않은" 미확인 상태 — 진짜 음성이 아님

따라서 낮은 점수는 `"명단공개 패턴과 닮지 않았다"`일 뿐이다.
**"안전"은 예측의 역방향이 아니라 관측 사실의 집계로만 정의한다.**

곧 무너질 회사도 붕괴 직전까지는 정상 회사와 데이터상 거의 같다. "안전"이라는 양성 지문은 존재하지 않는다.

## 판단할 수 없는 경우

| 상황 | 답변 방식 |
|---|---|
| 신설 1년 미만 | "데이터 축적 기간이 짧아 추이를 말씀드리기 어렵습니다." 변화율을 0으로 표시하지 않는다 |
| 가입자 5인 미만 | 표본 부족 — 변화율 지표 자체를 말하지 않는다 |
| 동명 사업장 여러 곳 | 임의로 고르지 않고 후보를 제시하고 되묻는다 |
| 매칭 신뢰도 0.8 미만 | "같은 이름의 다른 사업장일 수 있습니다"를 병기한다 |
| 검색 결과 0건 | "공개 데이터에서 찾지 못했습니다." "위험 사업장이 아닙니다"라고 말하지 않는다 |

**"모른다"고 말하는 경로를 반드시 밟는다.** 데이터가 적다는 것이 문제가 있다는 뜻은 아니라는 점도 함께 말한다.
