# 자주 나오는 독소조항 — 표현 사전

실제 근로계약서에 쓰이는 문구는 법 조문과 단어가 다릅니다.
같은 위반이라도 표현이 제각각이라, **문구를 보고 어떤 조문 문제인지 연결**하는 것이 진단의 절반입니다.

각 항목의 `code`는 `app/contract/rules.py`의 규칙 ID와 같습니다.

---

## 🔴 법정 기준 미달 — 조문이 명확한 것

| code | 계약서에서 보이는 문구 | 무엇이 문제인가 |
|---|---|---|
| `penalty_predetermined` | "중도 퇴사 시 교육비 ○○원을 배상한다" · "1년 미만 근무 시 위약금" · "무단결근 1일당 ○만원 공제" | 위약 예정 금지 (근기법 제20조) |
| `min_wage_below` | 월급÷월 소정근로시간이 시급 최저임금 미만 | 최저임금법 제6조. 미달분은 무효 |
| `probation_over_3m` | "수습기간 6개월" · "수습 1년" | 감액은 3개월까지만 (최저임금법 시행령 제3조) |
| `probation_rate_low` | "수습기간 중 급여의 70%" · "80% 지급" | 감액 하한 90% |
| `probation_short_term` | 계약기간 1년 미만인데 수습 감액 | 1년 미만 계약은 감액 불가 |
| `overtime_over_12h` | "주 60시간 근무" · "1주 연장근로 20시간에 동의한다" | 연장 12시간 한도 (제53조) |
| `no_annual_leave` | "연차휴가는 부여하지 않는다" · "연차수당 없음" | 제60조 (5인 이상) |
| `no_weekly_holiday` | "주휴수당은 별도로 지급하지 않는다" | 제55조① — 5인 미만에도 적용 |
| `severance_waived` | "퇴직금은 지급하지 않는다" · "퇴직금을 월급에 포함한다" | 퇴직급여법 제4조·제8조. 분할약정은 무효 |
| `wage_offset` | "손해 발생 시 급여에서 공제한다" · "대여금은 급여에서 상계" | 전액 지급(제43조)·전차금 상계 금지(제21조) |
| `forced_saving` | "급여의 일부를 회사 명의 통장에 적립한다" | 강제 저금 금지 (제22조) |
| `at_will_dismissal` | "회사가 필요하다고 인정하면 언제든 해고할 수 있다" | 제23조 (5인 이상) |
| `marriage_retirement` | "혼인·임신 시 퇴직한다" | 남녀고용평등법 제11조② — 무효 |
| `no_break` | 8시간 근무인데 휴게시간 0분 또는 30분 | 제54조 |
| `missing_required` | 임금 구성항목·소정근로시간·휴일·연차·근무장소 중 누락 | 제17조 |

## 🟡 확인 필요 — 그 자체로는 위법이 아닌 것

이 항목들을 🔴로 올리면 **정상 계약서까지 부당하다고 말하게 됩니다.** 반드시 분리합니다.

| code | 문구 | 왜 확인이 필요한가 |
|---|---|---|
| `inclusive_wage` | "월급에 연장근로수당을 포함한다" (포괄임금) | 근로시간 산정이 어려운 경우에만 유효. 실제 연장근로가 고정분을 넘으면 차액 청구 가능 |
| `fixed_ot_hours_unclear` | 고정연장수당은 있는데 **몇 시간분인지 미기재** | 초과 여부를 계산할 수 없음. 시간 수를 확인 |
| `probation_ok` | "수습 3개월, 90% 지급" | 계약기간 1년 이상 + 단순노무업무가 아니어야 유효 |
| `damages_actual` | "실제 발생한 손해를 배상한다" | 금액을 미리 정한 것이 아니므로 위약 예정이 아님 |
| `noncompete` | 퇴직 후 경업금지 | 기간·지역·대상이 과도하면 무효. 보상 유무가 쟁점 |
| `confidentiality_penalty` | 비밀유지 위반 시 손해배상 | 금액을 미리 못 박으면 제20조 문제로 넘어감 |
| `duty_change_broad` | "회사의 필요에 따라 업무·근무지를 변경할 수 있다" | 통상적 인사권 범위면 유효. 생활상 불이익이 크면 다툼 |
| `headcount_unknown` | 상시 근로자 수 미기재 | 5인 미만이면 가산수당·연차 조항이 적용되지 않음 |
| `holiday_unpaid` | "공휴일은 무급" | 5인 이상이면 제55조② 위반, 5인 미만이면 적법 |

## 🟢 기준 충족일 때 확인되는 것

빠짐없이 적혀 있으면 그것도 알려줍니다. 문제만 나열하면 사용자가 계약서 전체를 불신하게 됩니다.

- 임금의 구성항목·계산방법·지급방법이 나뉘어 적힘
- 소정근로시간이 1일·1주 단위로 명시되고 휴게시간이 별도 표기
- 주휴일과 연차유급휴가가 조항으로 존재
- 시급 환산액이 해당 연도 최저임금 이상
- 4대보험 가입 표기
- 계약서 2부 작성·근로자 교부 문구

---

## 표현 규칙

- **"위법입니다"라고 단정하지 않습니다.** "근로기준법 제20조는 ○○를 금지합니다"처럼 조문이 무엇을 정하는지 말하고,
  이 계약서의 어느 문구가 거기에 닿는지 보여줍니다. 최종 판단은 노동청·노무사 몫입니다.
- 계약서를 점수·등급으로 요약하지 않습니다. 조항별로 봅니다.
- 사업장 실명을 위험과 묶어 서술하지 않습니다. 진단 대상은 **문서**이지 회사가 아닙니다.
- 근거 없는 조문 번호를 만들어내지 않습니다. `standards.py`에 있는 조문만 인용합니다.
