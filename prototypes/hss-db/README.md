# DB 프로토타입 기여 기록

- 원본 브랜치: `feat/db`
- 보존 기준 커밋: `2b47b2f`
- 실제 공용 코드: 저장소 루트의 [`db/`](../../db/)

`feat/db`의 PostgreSQL 스키마, Drizzle 설정, 마이그레이션, ML export 적재 도구와 챗봇용 읽기 전용 뷰는 이미 `main`의 `db/`에 포함되어 있습니다.

코드를 이 폴더에 복제하면 두 DB 구현이 서로 달라질 수 있으므로, 이 폴더에는 기여 범위와 원본 커밋만 기록합니다. 이후 DB 개발도 루트 `db/`에서 진행합니다.

서버에 남아 있는 추가 산업안전 DB 작업은 담당자가 별도 브랜치로 커밋한 뒤 반영해야 합니다.
