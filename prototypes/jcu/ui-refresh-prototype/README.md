# 돈워리 UI 보완 정적 프로토타입

2026-08-10 UI 설문, 현재 `product`, CSH 초기 프로토타입과 SHYUN 랜딩을 비교해 만든 UI 실험본입니다.

## 실행

서버 없이 `index.html`을 브라우저에서 열면 됩니다. 로컬 정적 서버를 쓰려면 이 폴더에서 다음처럼 실행합니다.

```bash
python3 -m http.server 8080
```

그 뒤 `http://localhost:8080`으로 접속합니다.

## 포함한 보완점

- Product(B)의 2열 그라데이션 히어로와 데모 화면 구성을 메인 골격으로 사용
- `일하기 전에도, 일하는 중에도`와 `미리 알고 대비`를 결합한 돈워리 핵심 문구
- `서비스 소개 → 사업장 확인 → 계약서 진단 → 커뮤니티 → AI 상담` 순서로 랜딩과 메뉴 통일
- 데스크톱 헤더와 모바일 하단 내비게이션에서 AI 상담 강조
- 데스크톱 우측 하단의 고정 상담 버튼
- 메인·기능 화면 제목 크기와 정보 밀도 축소
- CSH의 경고 삼각형 브랜드 심볼과 둥근 옐로 로고 유지
- 위험카드를 Product(B)처럼 임금·산업안전 두 범주로 분리
- 임금 카드에 CSH/D의 체불 명단·건강보험 체납·국민연금·이직률·고지금액·고용 추이·폐업률·데이터 충실도 표시
- 산업안전 카드의 지역·업종 집계 수치는 유지하되 개별 사업장 위험확률·등급과 구분
- 출처·기준일·해석 한계는 각 카드의 접힌 영역에 배치
- JCU의 동명이인 검색·직접 선택 흐름과 `검색 → 위험카드 → 상담` 연결 유지
- 위험카드와 바로 연결되는 질문별 상담 CTA
- A의 질문 가이드형 상담 레이아웃과 B의 핵심 답변·확인 순서·공식 근거·해석 한계 출력 결합
- 속도·토큰 등 기술 정보는 접힌 상세 영역에서만 표시
- 별도 계약서 화면과 더미 검토 결과·후속 상담 연결
- 사용자에게 익숙한 목록형 커뮤니티와 브라우저 한정 더미 글쓰기
- 랜딩 커뮤니티 업종 필터와 별도 게시판의 검색·분류·익명 글쓰기 제공
- 계약서 페이지와 파일 없이 AI 상담부터 시작하는 보조 진입 경로를 함께 제공
- 푸터에서 Product의 근로감독관 전용 화면(`http://localhost:3000/inspector`)으로 연결
- 화면 전환·호버의 작은 모션과 `prefers-reduced-motion` 대응
- 모바일 1열 재배치와 고정 하단 메뉴

## 데이터와 연동 범위

- 사업장 검색과 위험카드는 고정 더미 데이터입니다.
- 상담 답변은 질문 유형에 따라 브라우저에서 조합하는 더미 답변입니다.
- 계약서 파일은 이름과 크기만 확인하며 내용을 읽거나 업로드하지 않습니다.
- 커뮤니티 글은 현재 페이지 메모리에만 추가되고 새로고침하면 사라집니다.
- 외부 API, RAG, LLM, DB를 호출하지 않습니다.
- 근로감독관 화면은 포함하지 않습니다.

이 폴더는 UI 비교·검토용이며 `product`의 실행 코드나 데이터 계약을 변경하지 않습니다.
