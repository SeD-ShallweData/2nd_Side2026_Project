# 팀원별 프로토타입

이 폴더는 통합 이전의 개인 작업물과 설계 결정을 보존합니다.

## 원칙

- 각 프로토타입은 원본 브랜치의 특정 시점을 기준으로 보존합니다.
- 통합 제품 개발은 `product/`에서 진행합니다.
- 프로토타입의 기능을 채택할 때는 원 작성자의 커밋과 기여 내역을 기록합니다.
- 서버 절대경로와 과거 실행 환경은 더 이상 유효하지 않을 수 있으므로 각 README의 환경 설명을 확인합니다.

## 목록

- `jcu/`: Next.js 통합 프로토타입
- `csh/`: Flask·프롬프트·가드레일·계약서 프로토타입
- `hb/`: 법령 RAG·계약서 검토 프로토타입
- `hss/`: DB 기여 범위 안내
- `shyun_64/`: Figma 추출 결과와 단일 HTML 랜딩 프로토타입
