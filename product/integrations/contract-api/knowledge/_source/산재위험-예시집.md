# 산재 위험 예측 — 예시집 (프로토타입 학습자료)

> 새 프로젝트에 그대로 옮겨 쓰기 위한 **예시 모음**입니다.
> 정확한 계수·성능수치보다 **"어떤 단위로 예측하고, 그 결과를 어떻게 말해야 하는가"** 를 익히는 것이 목적입니다.
> 이 문서의 수치는 **전부 예시값**입니다.

관련 원본 문서: `knowledge/specs/SPEC-0001`, `SPEC-0003`, `SPEC-0006`, `knowledge/decisions/ADR-0001`

## 0. 30초 요약

| 항목 | 내용 |
|---|---|
| 아이디어 | **민원이 산재보다 먼저 움직인다** — 민원을 선행신호로 써서 산재 발생건수를 예측 |
| 원천 데이터 | 국민권익위 민원분석정보 API(주), 산업재해현황(연), KOSIS 산업별 기업수(연) |
| 예측 단위 | **시도(17) × 산업(19) × 주차** |
| 예측 대상 | 산업재해 **발생건수** (회귀) |
| 리드타임 | 1~6주 선행 (민원 lag) |
| 출력 | 건수 + **시도별 분위수 기준 3단계 경보** |
| 설명 | SHAP top drivers |
| **화면에 나가는 것** | 지역×업종 집계 경보 (개별 사업장 특정 불가) |
| **화면에 안 나가는 것** | 개별 사업장의 사고 위험 |

> 🔑 제1원칙: **시도×업종 위험도를 개별 사업장에 부여하지 않는다.**
> 역방향 매핑은 **생태학적 오류(ecological fallacy)** 입니다. 화면에서는 항상 "이 사업장이 속한 지역·업종의 맥락"으로만 표기합니다.

## 1. 임금체불 모델과의 단위 차이

두 모델은 **네 축 전부** 다릅니다. 합치기 전에 이걸 먼저 이해해야 합니다.

| 축 | 체불 모델 | 산재 모델 |
|---|---|---|
| 공간 | 사업장 (도로명주소) | 17개 시도 |
| 산업 | 국민연금 업종코드 → KOSIS 18 대분류 | 19개 산업군 |
| 시간 | 월 | 주차 |
| 예측 대상 | 명단공개 여부 (이진 분류) | 발생건수 (회귀) |
| 출력 | 확률 0~1 | 건수 + 3단계 경보 |
| 리드타임 | 6개월 전 | 1~6주 전 |

> ⚠️ **두 모델의 출력을 산술적으로 합치거나 곱하지 않습니다.**
> 단위·의미·불확실성이 전부 달라서 합성 점수는 해석 불가능해집니다.
> 대신 **레이어를 분리해 병렬 표시**합니다. 체불 = 사업장 레이어, 산재 = 지역·업종 맥락 레이어.

### 2-3. lag 피처 생성 예시

민원의 **선행성**을 쓰려면 lag를 만들어야 합니다.

```python
LAGS = [1, 2, 3, 4, 5, 6]   # 주 단위

for cat in ["산업안전", "노동노정", "건설행정", "환경"]:
    for lag in LAGS:
        df[f"{cat}_lag{lag}"] = df.groupby(["region_code"])[cat].shift(lag)
```

생성 결과 (경기도 × 건설업 × 2026-07-13 행):

| 피처 | 값 | 의미 |
|---|---|---|
| `산업안전_lag1` | 218 | 1주 전 산업안전 민원 |
| `산업안전_lag2` | 203 | 2주 전 |
| `산업안전_lag3` | 167 | 3주 전 |
| `건설행정_lag1` | 301 | 1주 전 건설행정 민원 |
| `노동노정_lag2` | 101 | 2주 전 |
| `기업수_활동` | 48,200 | KOSIS 연간 (노출 보정용) |
| `기업수_신생률` | 0.081 | 신생 기업 비율 |
| `과거재해_4주평균` | 117.8 | 자기회귀 성분 |
| `계절_주차` | 28 | 연중 주차 (계절성) |

> 📌 **노출(exposure) 보정을 빼먹지 마세요.** 경기도 건설업 재해 건수가 많은 건 위험해서가 아니라 사업장이 많아서일 수 있습니다. `기업수`를 offset이나 분모로 넣어야 "위험도"가 됩니다.

## 3. 경보 산정 예시 ⭐

### 3-1. 규칙

**시도별 분위수 기준 3단계.** 전국 공통 절대 기준을 쓰면 경기도는 늘 위험, 제주는 늘 정상이 됩니다.

| 등급 | 기준 | 색 |
|---|---|---|
| `normal` (정상) | `predicted < 시도별 Q70` | 회색 |
| `warning` (주의) | `Q70 ≤ predicted < Q90` | 노랑 |
| `danger` (위험) | `predicted ≥ 시도별 Q90` | 빨강 |

> ⚠️ 창종설 계획서에는 4단계(정상/주의/경계/위험)가 적혀 있지만 **3단계로 통일**하는 것을 권장합니다. 산재 모델의 분위수 기준이 이미 검증되어 있고, 4단계는 사용자에게도 구분이 모호합니다.

### 3-2. 계산 예시 4건

```python
level = "danger" if pred >= q90 else "warning" if pred >= q70 else "normal"
risk_ratio = round(pred / baseline, 2)   # baseline = 최근 8주 이동평균
```

| # | 시도 | 업종 | 예측 | Q70 | Q90 | baseline | risk_ratio | 등급 |
|---|---|---|---|---|---|---|---|---|
| 1 | 경기도 | 건설업 | 141.2 | 108.5 | 93.8→**131.0** | 93.8 | **1.51** | 🔴 `danger` |
| 2 | 인천광역시 | 건설업 | 128.0 | 112.0 | 145.0 | 90.0 | 1.42 | 🟡 `warning` |
| 3 | 인천광역시 | 제조업 | 61.3 | 88.0 | 104.0 | 58.0 | 1.06 | ⚪ `normal` |
| 4 | 제주특별자치도 | 건설업 | 6.0 | 5.5 | 8.0 | 4.9 | 1.22 | 🟡 `warning` |

읽는 법:

- **#1** — 예측이 시도별 Q90을 넘었고 baseline 대비 1.5배. 가장 강한 경보.
- **#2** — Q70~Q90 구간. `risk_ratio`는 1.42로 높지만 인천 건설업은 원래 변동이 커서 Q90에 못 미침. **비율만 보면 안 되는 이유.**
- **#3** — `risk_ratio` 1.06인데 정상. 절대 건수는 61건으로 적지 않지만 인천 제조업 평시 수준.
- **#4** — 절대 건수 6건. **작은 시도는 표본이 작아 등급이 튑니다.** 최소 건수 임계(예: 5건 미만이면 경보 미산출)를 두는 것을 권장.

> 📌 `risk_ratio`와 `level`은 **다른 기준**입니다. 둘 다 보여주되, 등급의 근거는 분위수임을 명시하세요.

### 3-3. 성능 지표

| 지표 | 값 | 해석 |
|---|---|---|
| TPR (재현율) | 78.12% | 실제 위험 주차의 78%를 경보로 잡음 |
| Precision | 90.09% | 경보를 울린 것 중 90%가 실제 위험 |

> 체불 모델과 달리 **표본이 크고 세팅이 명확해서 방어가 쉽습니다.** 발표에서 성능 주장의 무게중심을 이쪽에 두는 것이 전략적으로 유리합니다.

## 6. 챗봇 응답 예시

### 예시 1 — 지역·업종 맥락 질문

**👤** 인천 건설현장 요즘 위험한가요?

**🤖**
> 인천광역시 건설업은 이번 주(2026-07-13 기준) **주의** 단계입니다.
>
> 예측 발생건수는 128건으로 최근 8주 평균(90건)보다 높습니다. 2주 전 산업안전 관련 민원과 지난주 건설행정 민원이 늘어난 것이 주요 신호입니다.
>
> 이 수치는 **인천광역시 건설업 전체를 묶어서 본 것**이며, 특정 현장이나 사업장의 사고 위험을 뜻하지 않습니다.
>
> 현장에서 확인해 보시면 좋은 것:
> · 안전교육 실시 여부와 주기
> · 안전보호구 지급 상태
> · 위험작업 시 2인 1조 운영 여부
> · 사고 발생 시 보고 절차

### 예시 2 — 개별 사업장으로 물어볼 때 ⭐ (생태학적 오류 방어)

**👤** 그럼 샘플A건설도 위험한 거네요?

**🤖**
> 그렇게 읽으시면 안 됩니다.
>
> 방금 말씀드린 **주의** 단계는 인천광역시 건설업 **전체를 합쳐서** 본 수치입니다. 이 지역·업종에 속한 개별 사업장 각각이 그만큼 위험하다는 뜻이 아닙니다. 같은 지역·업종 안에서도 현장마다 안전관리 수준은 크게 다릅니다.
>
> 샘플A건설 개별 사업장의 사고 위험은 저희가 갖고 있는 데이터로 판단할 수 없습니다.
>
> 대신 확인해 보실 수 있는 것은 있습니다. 고용노동부는 산업재해 발생 사업장 중 일정 요건에 해당하는 곳을 **공표**하고 있어서, 그 명단은 조회하실 수 있습니다.

> 📌 **이 응답은 반드시 고정 문구로 준비하세요.** 사용자는 거의 항상 이 질문을 합니다.

### 예시 3 — 등급 비교 요청

**👤** 인천이랑 경기도 중에 어디가 더 위험해요?

**🤖**
> 두 지역의 등급을 직접 비교하기는 어렵습니다.
>
> 저희 경보는 **시도별로 각각의 평상시 수준과 비교해서** 산출합니다. 인천의 "주의"와 경기의 "위험"은 서로 다른 기준선 위에서 나온 값이라, 등급만 놓고 어디가 더 위험하다고 말할 수 없습니다.
>
> 이번 주 기준으로는 경기도 건설업이 자기 지역 평시 대비 1.51배, 인천 건설업이 1.42배입니다. 다만 이 비율도 지역별 변동성이 달라서 절대적인 비교는 아닙니다.

### 예시 4 — 재해 발생 후 (`action_guide`)

**👤** 현장에서 다쳤어요. 어떻게 해야 하나요?

**🤖**
> 먼저 치료가 우선입니다. 산재보험 적용 의료기관에서 진료받으시면 됩니다.
>
> **1단계 — 사업주에게 알리기**
> 재해 발생 사실을 사업장에 알립니다. 사업주가 신고를 거부해도 근로자가 직접 신청할 수 있습니다.
>
> **2단계 — 요양급여 신청**
> 근로복지공단에 요양급여신청서를 제출합니다. 의료기관을 통해서도 가능합니다.
>
> **3단계 — 증거 확보**
> 사고 경위, 목격자, 현장 사진, 진료기록을 남겨두세요.
>
> **4단계 — 상담**
> 근로복지공단 1588-0075에서 상담하실 수 있습니다.
>
> 산재 인정 여부는 근로복지공단이 판단하며 제가 단정해 드릴 수 없습니다.

### 예시 5 — 데이터 없음

**👤** 제주도 숙박업 산재 위험은요?

**🤖**
> 제주특별자치도 숙박·음식점업은 이번 주 발생건수 예측이 통계적으로 의미 있는 수준이 아닙니다. 해당 지역·업종의 주간 재해 건수가 적어서 경보를 산출하지 않았습니다.
>
> 건수가 적다는 것이 안전하다는 뜻은 아닙니다. 표본이 작아 예측의 신뢰구간이 너무 넓다는 의미입니다.

### 예시 6 — 신고 경로

**👤** 현장이 너무 위험한데 신고할 수 있나요?

**🤖**
> 네, 몇 가지 경로가 있습니다.
>
> · **고용노동부 안전신문고 / 근로감독 신고** — 산업안전보건법 위반이 의심되는 경우
> · **작업중지 요청** — 급박한 위험이 있는 경우 근로자는 작업을 중지하고 대피할 수 있습니다
> · **1350** — 일반 상담
>
> 신고를 이유로 한 불리한 처우는 법으로 금지되어 있습니다. 다만 개별 사안이 법 위반에 해당하는지는 관할 고용노동청에서 확인하시는 것이 정확합니다.
>
> 신고 전에 사진, 작업지시 내역, 날짜를 기록해 두시면 도움이 됩니다.

## 8. 단위 정렬 예시 (두 모델을 한 화면에 띄울 때)

### 8-1. 공간 축 — 단방향만

```
사업장 도로명주소 → 시도 코드(행정표준코드 2자리) → 산재 모델의 17 시도 키
```

| 방향 | 허용 |
|---|---|
| 사업장 → 시도 (맥락 조회) | ✅ |
| 시도 위험도 → 개별 사업장 부여 | ❌ 생태학적 오류 |

### 8-2. 산업 축 — crosswalk 테이블

현재 **세 가지 분류 체계**가 돌아다닙니다.

| 체계 | 분류 수 | 쓰이는 곳 |
|---|---|---|
| 국민연금 업종코드 | 세분류 | 체불 모델 입력 |
| KOSIS 산업 대분류 | 18 | 체불 모델의 소멸률 피처 |
| 산재 산업군 | 19 | 산재 모델 |

→ **KSIC 대분류(A~U)를 기준으로 공통 코드 테이블을 하나 만듭니다.**

```csv
# industry_crosswalk.csv
industry_code,label,npc_code_pattern,kosis_major,sanjae_group,note
F,건설업,41*|42*,건설업,건설업,1:1
C,제조업,10*~34*,제조업,제조업,1:1
H,운수및창고업,49*~52*,운수업,운수·창고·통신업,산재 쪽이 통신 포함
Q,보건업및사회복지,86*~87*,보건·사회복지,기타의사업,산재 쪽 대분류가 거침
M,전문과학기술,70*~73*,전문·과학·기술,기타의사업,매핑 손실 있음
```

> 📌 **매핑 실패율을 반드시 기록하세요.** 화면의 "데이터 신뢰도" 표시에 그대로 반영됩니다.
> fallback은 키워드 기반 매핑.

## 9. 자주 빠뜨리는 엣지 케이스

| 상황 | 잘못된 동작 | 올바른 동작 |
|---|---|---|
| 주간 건수 5건 미만 | 그대로 등급 산출 | 경보 미산출 + "표본 부족" 표기 |
| 노출 보정 누락 | 경기도가 항상 위험 | `기업수`로 정규화 |
| 전국 공통 임계값 | 제주는 항상 정상 | 시도별 분위수 |
| 명절·연휴 주간 | 급감을 "개선"으로 해석 | 영업일수 보정 또는 예외 표기 |
| 민원 데이터 지연 | 최신 주차 예측 실패 | 마지막 확정 주차 명시 (`as_of`) |
| 산업 매핑 실패 | 임의 대분류 배정 | `unmapped` 유지 + 신뢰도 하향 |
| 두 모델 점수 합산 | 해석 불가능한 합성 점수 | 레이어 분리 병렬 표시 |
| 등급을 사업장 배지로 표시 | 생태학적 오류 | 별도 맥락 블록에 배치 |
