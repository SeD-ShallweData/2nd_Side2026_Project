# 시스템 프롬프트

LLM에 보내는 시스템 프롬프트를 코드에서 분리해 둔 곳입니다. 문구를 고칠 때
TypeScript를 건드리지 않아도 되고, 프롬프트 변경 이력이 코드 diff에 섞이지 않습니다.

| 파일 | 쓰이는 곳 |
| --- | --- |
| `chat/system.md` | 사용자 상담 — `DualLlmChatProvider` |
| `inspector/system.md` | 근로감독관 상담 — `inspectorService` |
| `rewrite/system.md` | 후속 질문 재작성 — `queryRewriteService` |

## 고치는 법

파일을 저장하면 끝입니다. 로더가 파일 수정 시각을 보고 다시 읽으므로 개발 중에는
서버를 재시작하지 않아도 반영됩니다.

```bash
vi prompts/chat/system.md
npm test          # 정책 문장이 빠지지 않았는지 검사
```

## 규칙

- **한 줄에 지침 하나.** 파일 내용이 그대로 시스템 메시지가 됩니다. 머리말이나
  마크다운 장식을 넣지 마세요. 모델이 그 형식을 따라 하거나 그대로 노출할 수 있습니다.
- **요청마다 달라지는 값은 넣지 않습니다.** 컨텍스트 JSON·정책 버전·상담 모드는
  호출부에서 뒤에 붙입니다.
- **키·접속 문자열·내부 필드명을 적지 않습니다.** `promptLoader.test.ts` 가 검사합니다.
- 빠지면 안 되는 정책 문장은 `promptLoader.test.ts` 의 "빠지면 안 되는 정책 문장"
  블록에 걸려 있습니다. 문장을 의도적으로 바꿀 때는 그 테스트도 함께 고치세요.

## 주의

시스템 프롬프트에는 가드레일 지침이 들어 있어, 파일이 없으면 정책이 적용되지 않은
답변이 나갑니다. 그래서 로더는 파일이 없거나 비어 있으면 조용히 넘어가지 않고
바로 실패합니다.

경로는 기본적으로 프로세스 작업 디렉터리의 `prompts/` 입니다. 다른 위치를 쓰려면
`PROMPT_DIR` 환경변수를 지정합니다.
