[UI/UX 개선 요청] 메인 화면 버튼 색상 및 '근로감독관 전용' 메뉴의 숨김 및 시각적 위계 문제 , 타이포그래피(폰트·크기·행간) 수정

버튼 색상 변경: 돈 워리 들어갔을 때 맨 밑으로 내려가면 '무료로 위험카드 보기' 버튼이 있습니다. 노란색 배경에 노란색 버튼이 묻혀 보입니다. '무료로 위험카드 보기' 버튼을 검정색 배경으로 변경해 시선 집중도를 높이고자 합니다. 

'근로감독관 전용' 메뉴의 숨김 및 시각적 위계 문제: 화면 최하단 어두운 영역에 노란색 글씨로 아주 작게 근로감독관 전용 ↗ 아이콘이 숨어 있습니다.
기획상 '일반 사용자' vs '근로감독관'의 화면 구성 및 제공 정보가 명확히 분리되어야 하는데, 일반 사용자가 잘못 눌러 진입하거나 근로감독관이 이 기능을 찾기 어렵습니다.
상단 네비게이션 바 우측 구역으로 올려 명확한 모드 전환(일반 사용자 ↔ 근로감독관)을 제공하고자 합니다.

타이포그래피(폰트·크기·행간) 수정: 메인 문구("일하기 전에도, 일하는 중에도...")의 폰트 크기에 비해 서브 설명 문구의 글자 크기가 너무 작거나 색상 대비가 낮아 가독성이 떨어집니다. 폰트도 다른 걸 사용하면 어떨까 싶습니다.

 [5종 상태별 배지 및 UI 표시 정책 설계]

### 1. 샘플 5종 상태별 배지 및 문구 정책
승석님 피드백(`docs/data-contract/README.md` 참고)을 반영하여, 회사의 위험을 단정 짓지 않고 '확인과 행동'을 유도하도록 5가지 상태별 UI 표현을 정의합니다. 대다수(85.7%)를 차지하는 '유보' 상태에서 과도한 경고색을 배제합니다.

- **`normal` (안정신호, 6.5%):**
  - **배지 문구:** `뚜렷한 이상 신호 없음`
  - **배지 스타일:** 차분한 초록톤 또는 파란톤 - 붉은색 계열 사용x
  - **한 줄 설명:** 현재 공공 데이터상 관측된 주요 이상 신호가 발견되지 않았습니다.
  - **고지 사항:** "본 서비스의 신호는 과거 공공 데이터를 기반으로 한 참고용 지표이며, 기업의 절대적인 안전이나 고용 안정을 보장하지 않습니다."
  -**보여줄 것 / 숨길 것:** 보여줄 것: 신호 요약 정보 / 숨길 것: 단정적 안전 등급, 확정적 표현

- **`watch` (유보, **85.7% 최다수**):**
  - **배지 문구:** `추가 확인 권장`
  - **배지 스타일:** 노란색계열 (안 쓸 색상: 빨강 — 대다수 기업이 해당하므로 공포감 유발 방지)
  - **한 줄 설명:** 입사 전 근로조건과 계약 내용을 꼼꼼히 확인하는 것을 권장합니다.
  - **고지 사항:** "위험 기업 판정이 아니며, 입사 전 근로조건을 면밀히 확인하기 위한 권장 안내입니다."
  - **보여줄 것 / 숨길 것:** 보여줄 것: 구직자가 확인할 행동 가이드 / 숨길 것: "위험 기업", "블랙리스트" 등 오인 유발 표현, SHAP 영문 피처명  

- **`unknown` (유보_정보부족, 3.5%):**
  - **배지 문구:** `분석 자료 부족`
  - **배지 스타일:** 주황 - (안 쓸 색상: 빨강, 노랑)
  - **한 줄 설명:**	해당 사업장에 대한 충분한 데이터가 누적되지 않아 분석할 수 없습니다.
  - **고지 사항:** "⚠️ 자료 부족은 '안전'을 의미하지 않습니다. 정보가 부족할수록 면접·계약 시 직접 적극적으로 확인해야 합니다." (역방향 오독 방지)
  - **보여줄 것 / 숨길 것:** 보여줄 것: 데이터 분석 대상 부족 상태 안내 / 숨길 것: 임의의 안전 점수

- **`partial-unavailable` (부분 장애, HTTP 200):**
  - **배지 문구:** `일부 정보 확인 불가`
  - **배지 스타일:** 회색 (안 쓸 색상: 빨강)
  - **한 줄 설명:**	데이터베이스 연결 일부 지연으로 임금 또는 산재 신호 중 일부 항목만 조회되었습니다.
  - **고지 사항:** "시스템 상태에 따라 일부 신호 카드가 누락될 수 있으며, 누락된 항목이 기업의 안전을 의미하지 않습니다."
  - **보여줄 것 / 숨길 것:** 보여줄 것: 정상 조회된 카드만 렌더링, 빈 카드는 '일시적 확인 불가' 명시 / 숨길 것: 누락된 신호를 임의로 '안전'으로 간주하여 표시하는 행위


- **`error-503` (전체 장애, HTTP 503):**
  - **배지 문구:** `카드 표시 불가`
  - **베지 스타일:** 진한 회색 (안 쓸 색상: 빨강, 노랑 — 에러 시 불필요한 공포감 조성 차단)
  - **한 줄 설명:** 서버 부하 또는 네트워크 문제로 신호 카드를 불러오지 못했습니다.
  - **고지 사항:** "시스템 오류로 인해 정보를 제공하지 못하고 있습니다. 잠시 후 다시 시도해 주세요."
  - **보여줄 것 / 숨길 것:**보여줄 것: 카드 자체를 숨기거나 에러 상태창 노출 / 숨길 것: Mock 성공 데이터나 임의의 안전 데이터로 위장하는 행위

### 2. 역할별 표시 항목 정의
로그인한 주체에 따라 화면을 열었을 때 노출되는 정보와 우선순위를 분리합니다. (나연님이 DB에 확정해둔 역할 이름 사용)

| 역할 | 화면 진입 시 최우선 표시 항목 | 비고 |
| :--- | :--- | :--- |
| **구직자** | 희망 지역·업종 중 신호 카드(임금/산재 분리) 및 입사 전 확인 행동 가이드 | 낙인 방지, 확인 중심 UI |
| **재직 근로자** | 구직자와 동일하게 처리 (현재 근로조건 확인 및 계약서 분석 연계) | |
| **기업·노무 담당자** | 자사의 현재 위치, 문제점 및 확인 필요 요인 | |
| **감독관** | 지역별 전체 현황, 위험큐, SHAP 사유 확인 | **※ `risk_tier` 등급 및 원점수는 반드시 감독관 화면에서만 노출 (구직자 화면 절대 금지)** |

### 3. 지역·업종별 거시적 시각화 화면 설계 방향
- **필요성:** 개별 회사 검색을 넘어 "인천 건설업 전체의 위험 신호 분포" 등 거시적 현황을 조망할 수 있는 뷰 필요.
- **설계 방향:** 기존 '사업장 확인' 탭 내에 거시 통계 요약 영역을 추가하거나 별도 탭으로 분리. 
- **포함될 내용:** 지역별/업종별 `watch` 및 `unknown` 비율 분포를 차트로 시각화하되, 특정 기업을 특정하여 낙인찍지 않도록 통계적 경향성만 안내.
