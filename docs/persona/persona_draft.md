## 페르소나 및 앱 사용 흐름

### 페르소나 A — 김취준 (25세, 20대 취준생/구직자 중심)
> 첫 정규직 면접 합격 통보를 받은 취준생. 회사에 대한 정보가 채용공고와 면접 인상뿐이라 불안함.
> **핵심 고충:** 근로계약서를 받아도 어떤 게 독소 조항인지 스스로 판단할 법적 지식이 부족함.

**사용 동선**
1. 검색창에 회사명 입력 → 동명 사업장 있을 경우 지역·업종으로 후보 구분
2. 위험카드 확인: 체불 위험 / 산재 위험 / 고용안정성 / 데이터 신뢰도를 분리해서 확인 (하나의 점수로 합쳐지지 않음)
3. "체불 위험 신호가 있다" → 관련 지역·업종 커뮤니티 게시판으로 이동해 같은 업종 종사자 경험 확인
4. 궁금한 점("이 정도면 정상인가요? 계약서에 뭘 확인해야 하나요?")을 AI 상담으로 질문 → 사업장 신호 카드 맥락이 반영된 답변 + 법령 근거 확인
5. 입사 예정 계약서를 업로드해 계약서 규칙 엔진 검토 → 누락·주의 조항 확인
6. 최종적으로 입사 여부 판단, 필요 시 게시판에 질문 남기고 결정

### 페르소나 B — 박감독 (34세, 근로감독관 보조/관리자 중심)
> 담당 관할 구역 내 다수 사업장 중 우선 점검 대상을 선별해야 하는 감독관.
> **핵심 고충:** 흩어져 있는 산재, 체불 데이터를 일일이 취합하고 비교하는 데 시간이 너무 오래 걸림.

**사용 동선**
1. 지역·업종 필터로 관할 사업장 목록 일괄 조회 (예: "인천 건설업")
2. 위험카드의 체불·산재 신호 수치 및 데이터 신뢰도를 기준으로 **우선순위 정렬** (신뢰도 낮은 항목은 별도 표시되어 성급한 결론 방지)
3. 신호가 높은 사업장의 **근거 데이터 상세보기**(어떤 공개데이터·시점 기준인지) 확인
4. 해당 지역 커뮤니티 게시판에서 실제 제보·경험담 교차 확인 (익명 제보이므로 참고용으로만 활용)
5. AI 상담으로 관련 법령·행정 절차(예: 근로감독 착수 요건) 빠르게 조회
6. 점검 우선순위 리스트를 내부 보고용으로 정리 (신호=단서, 최종 판정은 감독관 권한이라는 점을 UI 문구로도 재확인)
