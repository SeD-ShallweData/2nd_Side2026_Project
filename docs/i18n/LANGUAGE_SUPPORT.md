# 화면 언어 지원 기준 (내부 문서)

서비스 화면에는 검수 상태를 드러내지 않는다. 검수 상태와 근거는 이 문서와
[TRANSLATION_STATUS.md](TRANSLATION_STATUS.md)에서만 관리한다.

## 언어 구분

| 구분 | 언어 | 코드 | 비고 |
| --- | --- | --- | --- |
| 구현 | 한국어 | `ko` | 원문. 모든 사전의 기준 |
| 구현 | 쉬운 한국어 | `ko-easy` | 고령 동포 근로자용. 한국어 위에 덮어쓰는 부분 사전, 글자 118.75% 확대 |
| 구현 | 영어 | `en` | |
| 구현 | 중국어(간체) | `zh` | 줄바꿈 규칙 `word-break: normal` |
| 구현 | 베트남어 | `vi` | |
| 구현 | 태국어 | `th` | 줄바꿈 규칙 `word-break: normal`, 행간 1.75 |
| 지원 예정 | 우즈베크어·러시아어·네팔어·인도네시아어·크메르어 | `uz` `ru` `ne` `id` `km` | 선택 목록에 비활성 표시 + 팝업. 외국어 긴급 감지만 동작(영어로 답) |

## 고령 동포 근로자의 정의 (서비스 표시 문구의 근거)

> 재외동포(F-4)·방문취업(H-2) 등의 체류자격으로 한국에서 일하는 **만 60세 이상 한국계 외국 국적 근로자**.

- 근거: 외국인 산재 사망자 중 60세 이상이 26명(25.5%)으로 가장 많다. 방문취업의 84.5%, 재외동포의 73.7%가 한국계 중국인이다(`외국인 근로자 피해 통계 조사.md` 2.3절).
- 서비스는 누구나 쉬운 한국어를 고를 수 있게 하고, **나이나 체류자격을 묻거나 저장하지 않는다.**

## 지원 예정 언어 팝업 근거

| 언어 | 팝업 근거 문구 | 출처 |
| --- | --- | --- |
| 우즈베크어 | 외국인 산재 사망 3위(2025~2026.2Q 6명) | 고용노동부 국회 제출 자료(통계 조사 2.2절) |
| 러시아어 | (비움) | 국내 공식 통계 없음 |
| 네팔어 | 외국인 산재 사망 5위(4명) | 통계 조사 2.2절 |
| 인도네시아어 | (비움) | 국내 공식 통계 없음 |
| 크메르어 | 30인 미만 제조업 E-9 주요 국적 | 통계 조사 3.2절(추론값) |

근거가 비어 있는 언어는 팝업에 공통 안내("지금은 영어로 이용할 수 있습니다.")만 보인다.
러시아어·인도네시아어는 통계 근거 없이 후보에 오른 언어다. 공식 근거가 확인되면 이 표와
`product/src/i18n/messages/language.ts` 의 `pendingReason` 을 함께 채운다(확인: 조윤빈).

## 모델 사용 범위

- 화면 문구는 저장소의 고정 사전(`product/src/i18n/messages`)으로만 그린다. 상담 모델을 부르지 않는다.
- 외국어 긴급 안내는 고정 문구(`product/src/domain/multilingualEmergency.ts`)이며 모델을 부르지 않는다.
- 상담 답변 번역(2단계)부터 상담 모델을 쓴다. 범위는 질문·답변·현장 제보 번역으로 한정한다.
