## 검수 시 확인할 것
1. 판정하지 않는 표현이 유지되는가("누락 가능"이 "위법"·"없음"으로 바뀌지 않았는가).
2. 법령명·기관명·전화번호(1350, 119)·금액이 원문과 같은가.
3. 긴급 감지 사전이 현장에서 실제로 쓰는 표현을 빠짐없이 담는가(놓침 0건이 기준).
4. 쉬운 한국어가 짧고 쉬운가(고령 동포 근로자 기준).
5. 상담 번역(2단계): 번역 답변이 한국어 원문보다 단정적이지 않은가, 조문명이 한국어 원문으로 남았는가,
   보존 검사 실패로 한국어 대체(`korean_fallback`)되는 비율이 지나치게 높지 않은가(실측 전, 검증 필요).
