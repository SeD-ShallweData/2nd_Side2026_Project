# C4 계약서 규칙 반영안 — 팀 정책 검토용

기준: 2026-09-15 최신 main. [C4 판단안](2026-09-13-followup-review.md)을 규칙 엔진으로 옮긴 초안이다. #69에는 C4 법적 판정에 대한 리뷰·확정 댓글이 없었으므로 **팀이 아래 조건과 판정 레벨을 확인한 뒤 병합**한다. LLM 추출값과 계약서 문면만 사용하며 실제 근속·상시 인원·근로시간의 증거를 새로 확보하지 않는다.

## 1. 퇴직금

`SEVERANCE_MIN_MONTHS=12`를 계약기간 확인에 사용한다. 계약기간이 12개월 미만이거나 불명확하고, 계약서의 주 소정근로시간이 15시간 미만이거나 불명확하면 `severance.provided=false`와 인용된 `severance_waived`를 모두 **확인 필요**로 둔다. 동일 조항이 구조화 필드와 인용문에 나타나더라도 같은 조건을 적용한다. 12개월 이상 또는 무기계약이고 15시간 이상이라고 적힌 경우의 명시적 배제는 기존 위반 판정을 유지한다.

이는 계약기간을 실제 계속근로기간으로 단정하는 규칙이 아니다. 11개월 계약에도 이전 근무·갱신으로 실제 1년 이상일 수 있고, 계약서의 주 시간은 법이 요구하는 **4주 평균**의 증거가 아니다. [근로자퇴직급여 보장법 제4조](https://www.law.go.kr/LSW/lsInfoP.do?lsId=009883)와 [퇴직급여 설정 안내](https://easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=1&cciNo=3&cnpClsNo=1&csmSeq=999&popMenu=ov)를 기준으로 한다.

## 2. 가산수당

`overtime_premium_waived`를 추출 코드·인용 요건·규칙에 추가했다. **연장·야간·휴일 또는 가산수당 + 지급 배제 표현**이 원문에서 함께 확인된 조항만 제56조 지적으로 승격한다. 모델이 `other`로 분류해도 같은 엄격한 요건과 원문 대조를 통과한 경우에만 코드가 승격한다. 단순 포괄임금·수당 포함·산정 방식 불명은 명백한 배제로 처리하지 않는다.

상시 5인 이상 확인 시 위반, 5인 미만은 제56조 적용 제외, 인원 불명은 확인 필요다. 부족액 산정이나 유효한 보상휴가·특례 확인은 이 규칙의 범위에 없다. 근거는 [근로기준법 제56조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0056&lsiSeq=283457&urlMode=lsScJoRltInfoR) 및 제11조 적용 범위다.

추출 프롬프트는 자산 무결성 계약에 묶여 있으므로 프롬프트 파일 해시·길이와 고정 매니페스트 해시를 함께 갱신했다. 기존 자산을 우회하지 않는다.

## 3. 필수 명시 항목

기재 상태(`required_items`: true/false/null)와 내용 적정성을 분리했다. 7개가 전부 `true`여도 더 이상 녹색 `OK`를 내지 않고 **내용 확인 필요**를 표시한다. 추출된 임금 구성·지급일과 방법·근로시간·연차·장소/업무 필드에서 추가 확인할 내용을 제시하지만, 이것만으로 법적 적정성을 확정하지 않는다. `null`은 누락이 아닌 추출 불명으로 별도 표시한다.

서면교부 대상과 명시 대상도 구분한다. 무기계약 서면에 장소·업무가 없는 사실은 확인 필요로 두고, 기간제 계약의 장소·업무 누락에는 별도 [기간제법 제17조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0017&lsiSeq=232201&urlMode=lsScJoRltInfoR) 지적을 쓴다. 사업장 규모가 불명확하거나 5인 미만인 연차 누락은 제60조 적용을 가정하지 않는다. [근로기준법 제17조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0017&lsiSeq=283457&urlMode=lsScJoRltInfoR)의 서면교부 범위를 기준으로 했다.

현재 추출 스키마에는 단시간 근로자 여부와 항목별 원문 증거가 없으므로 단시간 근로자의 별도 서면명시 항목 전체, 각 조항의 실제 내용 적정성까지 자동 판정하지 않는다. 이 PR의 `확인 필요`는 그 한계를 사용자에게 드러내는 단계다.

## 검증 및 병합 조건

모의 추출값과 계약서 인용으로 11/12개월, 주 14/40시간, 4/5/불명 인원, 지급/배제 문구, 7항목 기재/누락/추출 불명을 회귀 검증한다. 실제 PDF 업로드·LLM 추출 정확도·과거 근속 자료는 별도 QA가 필요하다. 계약 규칙 담당과 법령 검토 담당이 **판정 레벨과 적용 범위**를 확인한 뒤 이 초안을 병합한다.
