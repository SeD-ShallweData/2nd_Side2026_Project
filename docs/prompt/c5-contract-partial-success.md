# C5 계약서 성공·법령 검색 실패 경로

성공한 review_contract가 있는데 retrieve_labor_law 도구만 실패하면 계약서 답변을 보존하고 검색 제한을 안내한다. 계약서 자체 또는 다른 필수 도구가 실패하면 기존 기본 안내로 대체한다. 미검증 법령 인용은 계속 출력 가드레일로 차단한다.

변경 전에는 어떤 도구든 ok:false가 있으면 성공한 계약서 답변까지 버렸다. 일반적인 RAG HTTP 장애는 unavailable 데이터로 정상 반환되므로 이 결함의 발생 조건과 구별한다. no_match·unavailable·도구 오류를 각각 검사한다.

이번 검증은 모의 runner 결과를 실제 상담 서비스에 넣어 출력·메타데이터·가드레일을 검사한다. 실제 LLM 프롬프트 준수율이나 업로드 E2E 측정은 아니다. 프롬프트만 고치는 대신 이미 확인된 서비스 분기의 손실을 제거한다.

팀 검토 사항: 계약 검토 성공을 검색 실패에도 활용하는 부분 성공 정책. 다른 실패의 차단 범위를 확대 완화하지 않는다. 실제 모델 검증 시에는 동일 합성 계약서에서 검색 성공·no_match·unavailable·도구 오류를 나누고 원답변·최종답변·인용·교체 여부를 기록해야 한다.
