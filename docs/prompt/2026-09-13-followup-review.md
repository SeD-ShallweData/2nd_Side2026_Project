## C3 단일 LLM 영향 검토

2026-09-08 결정 10 및 PR #38은 기본 Upstage, SKT 비교 옵션을 정했다. 현재 `getLlmProviderConfigs()`는 두 설정을 반환하고 `chatComparisonService`가 그대로 전달하므로 기본 단일 전환은 최신 main에서도 미구현이다.

`DualLlmChatProvider`는 전달받은 각 설정에 동일한 프롬프트 생성과 출력 가드레일을 적용한다. 이번 테스트는 Upstage와 SKT 각각 설정 하나만 넣어 실제 HTTP 호출 수가 1회이고, 안전 단정 답변이 기준 안내로 교체되는지 확인한다. 따라서 단일 설정에서도 이 경로의 보호 로직은 재사용 가능하다. 단일 모델 품질·속도·가격 비교를 측정한 결과는 아니다.

추천: 기존 팀 결정대로 Upstage를 기본으로 유지한다. 전환 담당은 요청의 compare 옵션→프로바이더 선택→결과 카드 수를 함께 연결하고 실행 메타데이터의 `dual_api`·`concurrent:true`도 단일 실행에 맞게 검토한다. API 키를 하나 지우는 방식은 단일 모드 구현이 아니며 실패 결과가 추가될 수 있다. 기본 전환 구현을 이 PR에서 대신 수행하지 않는다.

추가 관찰: 기존 SAFE_COMPANY_CERTAINTY는 ‘안전한 회사입니다’는 차단하지만 ‘이 회사는 안전합니다’는 차단하지 못했다(각 단일 모델 모의 응답에서 확인). 이는 모델 개수와 별개인 기존 표현 커버리지 공백이다. 이번 단일 모드 테스트는 기존 차단 대상 표현으로 보호 경로 재사용을 검증한다. 가드레일 전반의 안전 단정 차단을 보장하는 것으로 해석하지 않으며, 공통 가드레일 담당과 표현 범위를 별도로 보완해야 한다.

## C4-1 퇴직금 지급 요건

### 코드 결론

`standards.SEVERANCE_MIN_MONTHS`는 선언만 돼 있다. `rule_severance`와 `CLAUSE_RULES.severance_waived`가 각각 미지급을 위반 처리하므로 두 경로를 함께 고쳐야 한다. 계약기간 11개월만으로 실제 계속근로기간을 확정할 수 없다.

### 법적 근거 및 제안

계속근로 1년 미만 또는 4주 평균 주 소정근로시간 15시간 미만은 퇴직급여 설정 의무의 예외다. [법제처 퇴직급여 설정 안내](https://easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=1&cciNo=3&cnpClsNo=1&csmSeq=999&popMenu=ov). 단기 계약 반복과 실제 근로기간은 별도로 확인해야 한다. [고용노동부 2026-03-10 자료](https://moel.go.kr/news/enews/report/enewsView.do?news_seq=19054).

| 조건 | 제안 판정 |
| --- | --- |
| 지급 요건이 확인됐는데 지급을 배제 | 위반 지적 |
| 11개월 계약, 이전 근무·갱신 여부 불명 | 계속근로기간 확인 필요 |
| 실제 근속·근로시간이 법정 예외에 해당함을 확인 | 해당 법정 의무 위반으로 지적하지 않음 |
| 기간·소정근로시간 불명 | 확인 필요, 정상 판정하지 않음 |

월급 포함 약정은 단순 미지급과 분리한다. 월수 상수만 추가해 11개월을 일괄 정상 처리하는 수정은 하지 않는다. 향후 근로시간 15시간 전후, 날짜 기준 1년 전후, 갱신 계약, 양쪽 판정 경로의 중복을 회귀 검증한다.

## C4-2 가산수당 지급 배제

전용 조항 코드가 없어 명백한 가산수당 지급 배제가 `other`로 약화될 수 있다. 포괄임금 확인 규칙이 존재하는 것과 지급 배제 규칙이 있는 것은 다르다.

제56조는 연장·야간 50% 이상, 휴일 8시간 이내 50%·초과분 100% 가산을 정한다. [근로기준법 제56조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0056&lsiSeq=283457&urlMode=lsScJoRltInfoR). 상시 5인 이상 적용은 [고용노동부 안내](https://1350.moel.go.kr/rtmview.do?id=1000275737) 참조.

추천: 상시 5인 이상·해당 의무 적용·명시적 지급 배제 원문이 확인되면 위반 지적. 인원이나 조건 불명은 확인 필요. 5인 미만은 제56조 위반으로 자동 처리하지 않고 별도 약정상 의무를 구분한다. 문구가 없다는 사실만으로 미지급을 추정하지 않는다. 유효한 보상휴가 등 예외제도 확인 없이 현금수당 미지급 문구만으로 단정하지 않는다. 우선 명백한 배제 탐지를 구현하고 부족액 계산은 별도 과제로 둔다.

## C4-3 필수 7항목

현재 boolean은 ‘적혀 있는가’만 나타낸다. ‘연차 없음’도 기재는 됐으므로 항목 존재와 내용 적정성을 분리해야 한다. null(추출 불명)과 확정 누락도 구분한다.

| 항목 | 적정성 확인에 필요한 내용 예시 |
| --- | --- |
| 임금 구성 | 기본급·수당 등 구성과 금액/산정 근거 |
| 임금 계산 | 시간급·월급 등 단위와 계산 방식 |
| 임금 지급 | 지급일·지급 방식 |
| 소정근로시간 | 근로일·시간, 휴게와의 구분 |
| 주휴일 | 적용 요건과 휴일 기재 |
| 연차 | 사업장 규모·근로시간 등 적용 조건과 조항 내용 |
| 장소·업무 | 장소와 업무의 특정 여부, 계약 유형별 서면 의무 |

위 표는 제품 검토 기준 초안이지 독립적인 법정 7항목 목록이 아니다. 제17조제1항의 명시 의무와 제2항 서면교부 대상은 동일하지 않으며, 장소·업무는 시행령의 명시 대상이다. 기간제·단시간 계약에는 별도 서면 명시 규정이 있다. [근로기준법 제17조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0017&lsiSeq=283457&urlMode=lsScJoRltInfoR), [시행령 제8조](https://www.law.go.kr/LSW//lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0008&lsiSeq=270551&urlMode=lsScJoRltInfoR), [기간제법 제17조](https://www.law.go.kr/LSW//lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0017&lsiSeq=232201&urlMode=lsScJoRltInfoR).

추천 구조: 적용 여부(적용/비적용/불명), 기재 상태(확인/누락/불명확), 내용 판정, 원문 증거를 분리한다. 모든 항목이 적혀 있다는 이유로 적법이라고 결론 내리지 않는다. 기간제·단시간 적용 범위와 사업장 조건을 확정한 뒤 규칙을 구현한다.
