## 변경

- 목록을 손잡이 / 사업장 정보 / 오른쪽 작업 버튼 2개 열로 배치했다. 긴 이름과 좁은 폭에서는 정보가 줄바꿈되어도 버튼 그룹은 독립적으로 배치된다.
- 기존 사업장 검색의 입력칸·필터·검색 버튼 배열을 재사용해 회사명과 지역·업종 조건을 함께 적용한다. 선택지는 `/api/companies/filters`가 아니라 해당 계정의 **전체 관심 목록**에서만 계산한다. 검색 결과가 없어도 검색창과 필터를 남긴다. 관심 해제로 마지막 선택지가 없어지면 해당 조건을 해제한다.
- 왼쪽 노란 별 아이콘이 드래그 손잡이다. 마우스 드래그 또는 손잡이에 초점을 둔 상태에서 위·아래 화살표 키로 보이는 항목을 이동한다. 필터 중에는 보이는 자리만 재배치하므로 숨겨진 항목의 상대 순서는 유지된다.
- 순서는 `localStorage`의 `money-worry:favorite-order:v1:<user_id>` 키에 **회사 ID 배열만** 저장한다. 재진입 때 계정의 현재 API 목록과 대조해 해제된 ID와 중복을 제거하고 새 관심 사업장을 뒤에 붙인다. 같은 계정·같은 브라우저 범위이며 기기 간 동기화나 DB 스키마·API 계약 변경은 없다. 브라우저 저장 실패는 화면에 표시한다.
- 회사 상세는 관심 상태 조회 중 안내, 조회 실패 시 오류와 재시도, 성공 후 정확한 추가/해제 버튼을 표시한다. 브라우저 뒤로가기 캐시 복원 때 관심 목록과 상세 상태를 다시 조회한다. 새 지역명 번역은 `main`의 `companyMessages.regions` 변경이 이 브랜치에 합쳐질 때 관심 목록에도 적용되도록 해당 사전을 참조한다.
- 추가 문구를 한국어·영어·중국어·베트남어·태국어에 넣고 쉬운 한국어의 주요 문구를 별도로 보강했다.
