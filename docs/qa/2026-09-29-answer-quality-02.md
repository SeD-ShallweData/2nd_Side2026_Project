## 수정

- 기존 `ConversationRecallFact`에 퇴사일·하루 근무시간·사고 장소·미지급 잔액만 추가했다. 문장 속 회사는 소유자 확인 회사 목록으로 해석하고, 최신 정정을 우선한다. 부분 입금은 같은 사용자 진술에 총액과 입금액이 모두 있고 입금액이 총액 이하일 때만 계산한다. 회사가 불명확하거나 금액 근거가 부족하면 값을 만들지 않는다.
- 순수 회상·정정 확인을 생성 전 답변하고, 법률/행동이 섞인 질문은 기존 근거 경로로 보낸 뒤 사용자 진술 회상을 분리해 붙인다. 퇴사일의 이전 값에 관한 즉시 후속 질문은 최신 진술만 짚고 법정 달력 기한을 만들지 않는다. 1·2 번호 요청에는 사실과 확인 자료를 각각 쓴다.
- 생성 문맥에는 같은 회사·항목의 최신 소유자 확인 회상과 문서 상태를 별도로 제공한다. 원본·사본·통장 사본·명세서와 종류를 특정하지 않은 계약서를 구분한다. 문서의 `미진술`은 미보유·미교부로 바꾸지 않는다.
- 합성 원시 답변이 보유 서류를 부정하거나 미진술 서류의 부재를 단정하거나 입금액/잔액을 뒤집거나 공개 카드를 개인 입금 증거로 표현하면 가드가 교체한다. 교체 답변에는 사용자 진술의 출처 한계를 남긴다. 이전 작업의 동명 회사 카드/접근 경계와 비상 응답 우선순위는 유지했다.
