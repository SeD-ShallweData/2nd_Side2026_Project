## 변경

- 계약 결과의 한국어 설명과 다국어 화면에 함께 보이는 한국어 원문에 기존 `SafeMarkdown`을 적용했다. 강조·줄바꿈을 표시하며 HTML을 허용하지 않는다. 항목명과 한국어 원문 라벨은 기존 다국어 구성을 유지했다.
- 감독관·관리자가 공유하는 점검 보조 답변에 `SafeMarkdown`을 적용해 강조·목록·줄바꿈을 표시한다. 일반 사용자 상담의 렌더러는 변경하지 않았다.
- `/api/inspector/chat` 서비스에서 이 경로의 Upstage 설정 하나만 선택해 호출한다. 응답 계약은 `result` 단일 객체와 `response_id`로 바꾸고 비교 메타데이터를 제거했다. 공용 provider 설정, 프롬프트 본문·DB 활성 버전, 관리자 편집 기능은 변경하지 않았다.
- 제목·초기 안내·로딩·동의 문구·대화 이력을 단일 응답에 맞췄다. 이력에는 성공한 Upstage 답변만 AI 답변으로 넣고, 안전 교체나 호출 실패로 나온 DB 요약은 AI 답변 이력에서 제외한다. 실패 시 오류와 DB 요약 대체를 명시하고, 안전 교체도 별도 상태로 표시한다.
- `/api/inspector/chat`의 `requireInspectorRequest`와 `inspector/system`의 최소화된 내부 자료 구성은 유지했다. 감독관·관리자 접근과 내부 자료 전달 범위는 소스상 변경하지 않았다.

- 이번 단계는 사용자의 지시에 따라 **수정 후 검증을 수행하지 않았다**. 자동 테스트·타입 검사·린트·빌드·실제 브라우저 확인·외부 유료 provider 호출은 모두 미실시다. 구현 내용을 동작 통과로 판정하지 않는다.
