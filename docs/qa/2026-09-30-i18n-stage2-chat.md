# 언어 지원 2단계 — 상담 번역 피벗 QA

2026-09-30. 브랜치 `feat/i18n-s2-chat`. 설계: `Co끼리_언어지원_설계보고서.md` 3·4·5.1·5.2 B·7·8절.

## 범위

- 번역 경로: `product/src/services/chatTranslationPipeline.ts`(긴급 → 입구 → 한국어 파이프라인 → 출구·카드 문구),
  `translationService.ts`(Upstage 전용, temperature 0, 입구 12초·출구 20초 상한), `domain/translationGuardrail.ts`(보존·판정 검사).
- 적용 위치: `chatExecutionService`(dual_api·openai_responses 공통). 점검 보조 채팅은 번역하지 않는다.
- 화면: "한국어 원문 보기", 고정 사전 `verifyNotice`(공식 창구 재확인), `korean_fallback` 안내, 외국어 동의문 + 한국어 원문 동의문.
- 저장: `content`(사용자가 본 글)·`content_ko`·`locale`. 이력·회상·요약은 한국어.
- 운영 콘솔: `translate/system` 네 번째 프롬프트, 필수 정책 문장 6개.

## 입구 번역 실패 시 선택

원문 질문을 그대로 한국어 파이프라인에 넣는다. 사용자를 막지 않는 것이 우선이고, 상담 모델과 다국어 임베딩(BGE-M3)은
외국어도 읽는다. 생성된 한국어 답변은 출력 가드레일·인용 검증을 그대로 거친 뒤 출구 번역 보존 검사를 다시 받는다.
이때 `question_ko`는 남기지 않아 저장 `content_ko`도 비고, 다음 문맥은 원문을 쓴다. 한국어 정규식 규칙(의도·회상)이
빠질 수 있는 점은 알려진 한계다.

- 긴급 우회: 외국어 긴급 표현이면 번역기 호출 0회, 번역기가 멈춰 있어도 응답(`fixed_copy`, 한국어 원문 = 고정 긴급 문구).
- 입구 실패: 원문 질문으로 실행, `question_ko` 없음.
- 출구 보존 실패: 숫자 변경(14일 → 7일)·원문에 없는 "illegal" 추가 → `korean_fallback`. 통과한 번역은 「근로기준법」 제36조·고용노동부·1350 유지.
- 비교 모드: 결과마다 번역, 같은 답변은 한 번, 카드 문구는 두 결과를 모아 번호 목록 한 번.
- 카드 문구: 항목별 보존 실패만 한국어, 줄 수·번호 어긋나면 전부 한국어, 문구 번역 실패해도 답변 번역 유지.
- 한국어 통과: `undefined`·`ko`·`ko-easy`·`uz`는 같은 요청 객체로 한 번 실행하고 같은 응답 객체를 돌려준다(번역기 0회).
- 실행 모드: dual_api·openai_responses 모두 한국어 질문으로 실행하고 답변을 옮긴다. 점검 보조 코드가 번역 경로를 import 하지 않는다.
- 저장: `content`/`content_ko`/`locale` 저장, 한국어 이력 복원, 입구 실패 시 `content_ko` 없음, 한국어 상담 메시지 모양 불변,
  알 수 없는 locale·20,000자 초과 `content_ko` 미저장, 익명 가져오기 보존, 누적 요약이 한국어로 만들어짐.
- 키 없음: 모델 미호출, 원문 질문·한국어 답변으로 결정적 대체.
- 시연 질문 4개(vi·zh·th·en)의 자연스러운 한국어 번역이 입구 보존 검사를 통과.

## 실측(라이브) 번역 확인

**하지 못했다.** 이 워크트리와 메인 체크아웃의 `product/.env.local`에 Upstage 키 항목이 없고, 공유 키 파일(`SHARED_API_KEY_FILE`)도
설정돼 있지 않다. 모델 호출 0회. 따라서 실제 Solar Pro 3 출력이 보존 검사를 얼마나 통과하는지(`korean_fallback` 비율)는
**검증 필요**다. 시연 전 키가 있는 환경에서 아래 네 질문으로 한 번씩 확인할 것을 권한다.

- vi: "Công ty chưa trả lương 2 tháng, tôi phải làm gì?"
- zh: "公司已经两个月没发工资了,我该怎么办?"
- th: "นายจ้างไม่จ่ายค่าจ้าง 2 เดือนแล้ว ควรทำอย่างไร"
- en: "My employer has not paid me for 2 months. What should I do?"

확인할 것: 답변 카드가 화면 언어로 나오는지, 조문명이 한국어로 남는지, "한국어 원문 보기"·공식 창구 문장이 보이는지,
번역이 떨어지면 한국어 답변과 안내 문구가 보이는지(막히지 않는지).

## 배포 전 확인

- **0023 마이그레이션을 앱보다 먼저 적용**해야 한다. 새 코드는 대화 조회에서 `content_ko`·`locale`을 읽고 저장에서 쓴다.
  컬럼이 없으면 로그인 대화 저장·복원이 503(저장 불가)으로 떨어진다. 운영 콘솔의 `translate/system` 저장도 0023의 CHECK 변경이 필요하다.
- 동의 문구의 "같은 AI 공급자(Upstage Solar)"는 `dual_api` 기준이다. `openai_responses` 모드에서는 본 상담 공급자(OpenAI)와 번역 공급자(Upstage)가 다르다.
