## 집계 근거와 변경

- 임금체불 `v_region_industry_signal`은 현재 배치의 `scored_active`를 사업장별로 묶는다. 원본 `scored_active`와 `safe_recommendation`은 `(firm_id,batch_id)` 기본키를 가진다. 산업안전 읽기 뷰는 공표된 현재 실행을 읽고, 현재 실행은 범위별로 하나이며 대상 주차가 하나로 제한된다. 결과의 `(run_id,firm_id,target_week_start)`도 기본키다. 따라서 각 탭의 지역×업종 셀은 해당 탭 모집단의 사업장을 중복 없이 나누는 집계로 **소스상** 판단했다. 운영 DB의 실제 상태는 확인하지 않았다.
- 서비스에서 원본 구·신 지역명을 `canonicalRegion`으로 합쳐 같은 현재 지역·업종의 셀을 더한다. 필터 조회값도 정규화하므로 `광주광역시`·`전라남도`·`전남광주통합특별시`가 같은 통합 지역으로 조회된다. `강원도`·`전라북도` 등도 현재 명칭으로 묶인다. 지역 선택지는 공통 `regionOrder`의 행정 순서로 정렬한다.
- **건수 표시와 업종 건수순 정렬을 적용했다.** 같은 탭의 전체 셀을 기준으로 지역·업종 선택지를 만들며, 다른 차원의 현재 필터를 반영한 건수를 계산한다. 업종은 건수 내림차순, 같은 건수는 한국어 이름순이다. 선택지는 결과가 0곳이어도 남는다. 임금체불과 산업안전의 셀·건수·캐시는 서로 분리한다.
- 30곳 미만 셀은 차트 카드에서 계속 제외한다. 선택지나 현재 필터 총계에 이런 셀이 하나라도 포함되면 정확한 건수를 `null`로 보내 “건수 비공개” 또는 “총계 비공개”로 표시한다. 이에 따라 차트에 보이는 셀만 더한 값을 전체 건수로 잘못 표시하지 않고, 작은 셀을 합계 차이로 바로 역산하는 것도 막는다. 정확한 건수·건수순 정렬은 공개 가능한 선택지에만 적용한다. 0곳은 0으로 표시한다.
- 관리자 배치 현황의 규모 열을 `채점 / 위험큐 / 안정판정`의 독립된 행과 숫자로 배치했다. 좁은 화면의 필터 선택 폭을 제한하고 기존 표의 가로 스크롤을 유지했다. ML 학습·추론·판정 기준·원본 데이터, DB 스키마·마이그레이션·운영 DB는 변경하지 않았다.
