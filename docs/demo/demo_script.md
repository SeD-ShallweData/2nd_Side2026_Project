## 3분 시연 시나리오 (실제 화면 흐름 기준)

| 시간 | 단계 | 화면 조작 | 발표자 대사 |
|---|---|---|---|
| 0:00–0:20 | 오프닝 | 랜딩 화면("일하기 전에도, 일하는 중에도 미리 대비하는 Co끼리") | "면접에 합격했습니다. 그런데 이 회사, 정말 괜찮을까요? 체불 명단엔 아직 안 올라와 있고, 리뷰 사이트는 몇 년 전 글뿐이고, ChatGPT에 물어봐도 일반적인 답만 돌아옵니다. 저희는 이 공백을 채우는 서비스, Co끼리를 만들었습니다." |
| 0:20–0:45 | STEP 1 사업장 검색 | "사업장 확인" 진입 → "건설" 검색 → 결과 목록 노출 → 사업장 하나 "이 사업장 선택" | "회사명을 검색하면 동명 사업장이 많기 때문에, 저희는 첫 번째 결과를 자동으로 선택하지 않습니다. 지역과 업종을 직접 비교해서 정확한 사업장을 고르도록 안내합니다." |
| 0:45–1:30 | STEP 2 위험카드 확인 | 사업장 상세 화면 → 임금 카드·산업재해 카드 확대 → 하단 고지 배너 강조 | "여기서 중요한 건, 저희는 이 회사가 위험하다고 판정하지 않는다는 점입니다. 임금 지급 정보와 산업재해 확인 신호를 분리해서 보여드리고, 확인되지 않은 지표는 '확인할 수 없음'으로 솔직하게 표시합니다. 두 신호는 절대 하나의 점수로 합치지 않습니다." |
| 1:30–1:50 | STEP 3 체크리스트 | 입사 전 행동 체크리스트 화면 → 항목 몇 개 체크 → 카운터 변화 확인 | "모델이 주는 정보와는 별개로, 입사 전에 직접 확인해야 할 8가지 체크리스트도 함께 제공합니다." |
| 1:50–2:30 | STEP 4 AI 상담(병렬 비교) | "이 사업장을 기준으로 AI 상담" 버튼 → 빠른 질문 "이 회사는 안전한가요?" 클릭 → 두 모델 답변 동시 노출 | "체크리스트에서 바로 AI 상담으로 넘어갈 수 있습니다. '이 회사는 안전한가요?' 라고 물어도, 저희는 안전 여부를 단정하지 않습니다. Upstage Solar와 SKT A.X 두 국내 AI 모델이 같은 공식 근거로 동시에 답변하면서, 확인할 순서와 핵심 확인 사항만 알려줍니다. 법률 판단이나 전문가 상담을 대신하지는 않습니다." |
| 2:30–2:50 | STEP 5 계약서 진단 | "근로계약서 별도 검토" 화면 → 계약서 파일 업로드 → 확인된 항목·누락 가능·다시 물어볼 질문 결과 노출 | "실제 받은 계약서를 업로드하면, 확인된 항목과 누락 가능한 항목, 그리고 회사에 다시 물어볼 질문까지 정리해줍니다. 업로드한 원문은 서버나 Git에 저장하지 않습니다." |
| 2:50–3:00 | 클로징 | 랜딩 화면 복귀 | "판정이 아니라 확인. 낙인이 아니라 신호. Co끼리가 여러분의 첫 출근길을 지켜드리겠습니다. 감사합니다." |
