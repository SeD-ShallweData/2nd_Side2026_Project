## 3분 시연 시나리오

> 🟢 민서 확정 — 시간이 정 부족할 경우 트리밍 방법:
> 1. \*\*STEP 4 커뮤니티 작성·신고: 화면 조작 생략.\*\* 클릭·타이핑 없이 말로만 짧게 언급하고 바로 다음 단계로 넘어간다.
> 2. \*\*STEP 0 로그인: 대사 단축.\*\* "먼저 로그인부터 하겠습니다. 회원가입 없이도 대부분 기능을 쓸 수 있지만, 커뮤니티에 글을 쓰거나 신고를 하려면 로그인이 필요합니다." → \*\*"헤더 오른쪽 상단 로그인 탭에 들어가 로그인을 해줍니다."\*\*
>
> 아래 표는 시간 여유가 있을 때의 기본 버전이며, 각 셀에 단축판을 함께 표기했다.

> 본 시연은 '사용자' 페르소나(auth\_role='일반 사용자')의 \*\*구직 시나리오\*\*를 예시로 보여드립니다. 같은 계정이 자기 사업장(firm\_id)을 연결하면 "내 사업장 확인" 시나리오로도 이어지며, 감독관·관리자 페르소나는 질의응답에서 별도로 안내합니다.
