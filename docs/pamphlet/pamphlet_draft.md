## 팜플렛 초안

### 서비스 한 줄 소개

입사 전, 회사의 임금체불·산업안전 확인 신호와 공식 법령 근거를 한 번에 확인하는 노동정보 서비스, Co끼리

### 문제 정의

구직자·근로자는 입사를 결정하기 전 해당 사업장의 임금체불·산업재해 위험 정보를 확인할 방법이 마땅치 않습니다.

* 체불사업주 명단은 이미 확정된 이후에만 공개됨 (사후 정보)
* 리뷰 커뮤니티는 주관적 경험담에 의존해 신뢰하기 어려움
* 범용 AI 챗봇은 해당 사업장에 대한 실제 데이터 없이 일반적인 답변만 제공

### 주요 사용자

* **구직자·근로자** (주 사용자): 입사 전 회사 정보를 확인하고 싶은 사람
* **근로감독관** (보조 사용자): 점검 우선순위를 사전에 파악해야 하는 담당자

### 핵심 기능

* 사업장 검색 (동명 사업장 지역·업종 구분)
* 임금체불·산업안전 신호 확인 (분리된 카드로 제공, 하나의 점수로 합치지 않음)
* AI 노동 상담 (공식 법령 근거 기반, 국내 LLM 2종 병렬 답변)
* 근로계약서 검토 (필수 기재사항 점검)

### 사용 흐름

회사 검색 → 사업장 선택 → 위험정보 확인 → AI 상담 → (필요 시) 계약서 검토

### 차별점

Co끼리는 AI가 회사를 "안전하다" 또는 "위험하다"고 단정하지 않습니다.
공개 데이터와 공식 법령 근거를 있는 그대로 보여주고, 사용자가 무엇을 확인하고 다음에 무엇을 해야 할지 스스로 판단하도록 돕습니다.

### 기대효과

* 입사 전 정보 비대칭 완화
* 구직자·근로자의 사전 확인 역량 강화
