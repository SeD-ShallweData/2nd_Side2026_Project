## 유사 서비스 3개 비교 분석

| 구분 | 고용24 체불사업주 명단 | 리뷰 커뮤니티 (잡플래닛/블라인드) | 범용 LLM 챗봇 (ChatGPT 등) | **Co끼리** |
|---|---|---|---|---|
| 정보 성격 | 공공기관이 확정·공개한 **체불 확정 명단** (사후·행정 처분 결과) | 익명 개인의 **주관적 경험담·평점** | 사용자가 질문하면 **일반화된 법령 지식**으로 답변 | 공개데이터 기반 **사전 확인 신호** + 법령 근거 |
| 시점 | 체불이 이미 확정·공표된 **사후 시점** | 재직·퇴사 시점에 따라 들쭉날쭉, 최신성 보장 안 됨 | 시점 개념 없음 (일반론) | 입사 지원 **전** 시점에 확인 가능 |
| 신뢰도 표시 | 명단 자체는 신뢰 가능하나, **등재되지 않은 소규모·초기 체불은 누락** | 평점 조작·왜곡 가능성, 감정적 편향 큼 | 특정 사업장 실사례 반영 불가, **환각(hallucination) 위험** | 데이터 출처·신뢰도(%)를 카드에 함께 명시 |
| 판단 방식 | 명단 등재 여부만 확인 가능(이진법) | 별점·후기 텍스트로 간접 추정 | 사용자가 스스로 검색·해석해야 함 | 체불/산재/고용안정성 **신호를 분리 제공**, 점수로 낙인찍지 않음 |
| 행동 연계 | 정보 확인 후 어떻게 해야 할지 안내 없음 | 후기 확인 후 별도 검색 필요 | 상담은 가능하나 해당 사업장 맥락 없음 | 신호 확인 → **사업장 맥락 기반 RAG 상담**으로 바로 연결 |
| 한계 요약 | 이미 벌어진 사고에 대한 **사후 정보**, 예방 효과 낮음 | 신뢰성·객관성 부족, 표본 편향 | 법령은 알지만 **"이 회사가 어떤지"는 모름** | (아래 차별점 참고) |

**Co끼리의 차별점**
- 세 서비스 모두 "사후 확정 정보(고용24)", "주관적 경험(리뷰 커뮤니티)", "일반화된 지식(LLM)" 중 하나에 머무는 반면, Co끼리는 **입사 전 시점에 공개데이터 기반 사전 신호**를 제공해 예방적 판단을 가능하게 함.
- 특정 사업장을 "위험하다"고 확정 판정하지 않고 신호와 근거만 제시함으로써, 잡플래닛류의 **낙인·명예훼손 리스크**와 고용24 명단의 **경직성(등재 전까지는 정보 없음)** 사이의 간극을 메움.
- 범용 LLM과 달리 **해당 사업장의 신호 카드 데이터를 우선 학습(RAG)**시켜, 추상적 법령 설명이 아니라 "이 상황에서 다음에 뭘 해야 하는지"까지 안내.
