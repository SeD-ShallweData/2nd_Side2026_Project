# ADR-0002 · Flask + 빌드 없는 정적 프런트

- 상태: **채택**
- 날짜: 2026-08-01
- 결정자: csh

## 맥락

Figma Dev Mode 추출물은 React + Tailwind(TSX)입니다. 그대로 쓰려면 Node 툴체인이 필요합니다.

확인한 환경:

- `node`, `npm` **미설치** (공용 서버, 설치 권한 불확실)
- 홈 디스크 여유 20G — `node_modules`를 두기에 여유롭지 않음
- 팀이 revert 전에 쓰던 `webapp/`은 **Flask + `static/index.html`** 구조
- 팀원 6명이 같은 서버를 쓰며 파이썬 환경에 익숙

## 결정

**Flask + 빌드 없는 정적 HTML/CSS/JS.**

Figma TSX는 디자인 명세로만 읽고 구현은 새로 합니다.
색·수치는 `web/css/tokens.css`에 토큰으로 옮겨 시안 갱신 시 한 곳만 고치면 되게 했습니다.

## 근거

1. **의존성 0** — `pip install flask requests python-dotenv` 세 개면 끝. 팀원이 clone 후 바로 실행 가능
2. **팀 연속성** — 기존 팀 코드와 같은 스택
3. **시연 안정성** — 빌드 실패 지점이 없음. 발표장에서 `./run.sh` 하나로 뜸
4. **프롬프트 반복이 목적** — 지금 단계에서 프런트 프레임워크가 주는 이득이 없음

## 감수하는 것

- 컴포넌트 재사용을 JS 문자열 템플릿으로 처리 (내비게이션·푸터가 두 HTML에 중복)
- 타입 검사 없음
- 상태 관리가 커지면 한계 — 커뮤니티·마이페이지까지 확장하면 재검토 필요

## 되돌리려면

Node를 설치할 수 있게 되고 화면이 10개를 넘어가면 Vite + React로 옮깁니다.
그때 `web/css/tokens.css`는 그대로 재사용할 수 있고, `app/`의 API는 변경 없이 씁니다.
