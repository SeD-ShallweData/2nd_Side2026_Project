## 기록 규칙

- **결정에는 반드시 근거를 적습니다.** "그렇게 했다"가 아니라 "무엇 때문에 그렇게 했다".
- **버린 선택지도 적습니다.** 나중에 같은 논의를 반복하지 않기 위해서입니다.
- **날짜는 절대표기**(2026-08-01)로 씁니다. "어제", "지난주"라고 쓰지 않습니다.
- 되돌리기 어려운 결정은 `ADR/`에 별도 문서로 남깁니다.
