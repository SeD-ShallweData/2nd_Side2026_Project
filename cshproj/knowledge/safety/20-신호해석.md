# 경보 신호를 문장으로 옮기기

모델이 짚은 driver를 사용자 언어로 바꾼다. SHAP 값 자체는 화면에 나가지 않는다.

| driver | ✅ 이렇게 말한다 |
|---|---|
| 건설행정 민원 (1주 전) | 지난주 이 지역 건설 관련 민원이 평소보다 많이 접수됐습니다 |
| 산업안전 민원 (2주 전) | 2주 전 산업안전 관련 민원이 늘었습니다. 과거 이 패턴 뒤에 재해가 늘어난 경우가 있었습니다 |
| 노동노정 민원 (1주 전) | 지난주 근로조건 관련 민원이 늘었습니다. 장시간 근로가 늘어나는 시기일 수 있습니다 |
| 계절성 (연중 주차) | 여름철은 온열질환·고소작업 사고가 늘어나는 시기입니다 |
| 과거 산재 발생 추이 | 최근 몇 주간 이 지역·업종의 재해 건수가 늘어나는 흐름입니다 |
| 기업수 (신생률) | 이 지역·업종에 신규 사업장이 늘고 있습니다 |

## 민원이 선행신호가 되는 이유

| 카테고리 | 선행성 |
|---|---|
| 산업안전 | 현장 안전조치 미흡 신고. 사고보다 1~3주 앞선다 |
| 건설행정 | 공기 단축·무리한 시공 관련. 건설업에서 특히 강하다 |
| 노동노정 | 근로조건·과로 관련. 장시간 노동 → 사고 경로 |
| 환경 | 유해물질·소음. 직업병 계열 |

## 현장에서 확인할 항목

경보를 설명한 뒤에는 사용자가 실제로 확인할 수 있는 것을 준다.

- 안전교육 실시 여부와 주기
- 안전보호구 지급 상태
- 위험작업 시 2인 1조 운영 여부
- 사고 발생 시 보고 절차
- 작업 전 위험요인 공유 회의(TBM) 기록 여부

## 재해 유형은 구체적으로

추락, 끼임, 부딪힘, 절단·베임, 화재·폭발, 질식, 업무상 질병.
"위험합니다"로 끝내지 말고 어떤 유형이 왜 많은지 짚는다.

위험을 말할 때는 **어느 축 때문인지** 밝힌다.
"건설업이라서 위험합니다"가 아니라 "건설업 + 50인 미만 + 고소작업 조합에서 추락 재해 비중이 특히 큽니다"처럼 조합으로 설명한다.

위험을 가르는 축(우선순위 순): 업종 → 사업장 규모 → 작업 형태 → 고용 형태 → 재해·감독 이력.
사용자가 말하지 않은 축이 결론을 크게 바꾼다면 되묻는다. 한 번에 최대 3개까지.
